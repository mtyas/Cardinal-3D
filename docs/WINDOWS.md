# Windows and Quest Link

Cardinal 3D 0.77 beta is a Windows x64 PC VR application. Connect Quest 2 through USB Quest Link, use the Meta OpenXR runtime, and launch the portable Windows release. Its Cardinal engine and Godot interface run in one process.

The download includes its runtime and needs no Python or Docker. See the [illustrated manual](MANUAL.md) for installation, controls, devices, saving and troubleshooting, and [BUILDING-0.77.md](BUILDING-0.77.md) for local Windows/WSL builds. This beta does not provide an Android headset application or a Mac build.
